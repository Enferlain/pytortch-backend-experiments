# 5nb review disposition

The required `review-mcp` review of `HEAD` plus the explicitly named untracked
implementation/evidence returned **no blockers**. Its complete response and
tool trace are retained in [review.md](review.md).

1. **Evidence integrity:** added `evidence-integrity.json` and analyzer assertions
   for component/profiler/environment evidence. The analyzer checks all six
   upstream and exercised component-body digests, registry package pins against
   the retained probe lock, the actual NCU executable digest and exact command,
   the isolated compiler binary/lock, NVRTC/builtins and retained raw captures.
   The manifest freezes the reviewed artifacts; it is not regenerated by the
   analyzer. Existing 12,784-file and upstream revision/diff checks still pass.
2. **Unused telemetry:** removed the unconsumed launch event list. Kernel
   attribution and geometry remain evidenced by raw CUPTI traces and actual NCU
   launch/SASS data. No performance measurement was repeated or substituted.
3. **CPU producer binding:** `cpu_gate()` now checks the retained CPU phase
   driver against the CPU record before compiling. The retained producer is the
   right comparison because the driver subsequently grew GPU/timing phases.
4. **Idle-plane guard:** documented the modulo-wrap hazard beside the component
   boundary in the report. The guard and Rust body remain unchanged.
5. **Metadata ABI:** the runtime cross-checks the manifest against scalar and
   buffer counts derived from the admitted semantic descriptor (three scalar
   words plus two buffer-length words, 40 bytes).
6. **Template reads:** intentionally retained. This tiny explicit-only trial
   reads the frozen templates on admission; caching is unnecessary and would
   introduce an unrelated host optimization after the performance stop.
7. **Timing drift:** documented FP16/BF16 first-round drift without assigning a
   hardware-state cause. Every accepted round remains included, and the
   component loses all six matched round medians in every case.

After these small host/evidence corrections, the full GPU numerical validation
was repeated: **66 cases, 945,534 outputs**, 21 invalid live invocations and
three nondefault-stream/offset controls pass. The preceding GPU record is
retained in `pre-followup-gpu.json`. The analyzer confirms final qualified
IR/CUDA/PTX matches the timed code modulo entrypoint names, all **120** accepted
raw timing traces agree, and the historical source/evidence files are intact.
Focused checks in `check_followups.py` verify valid CPU/metadata admission and
rejection of modified CPU producer, metadata and provenance digests, without GPU
dispatch. Results are in `followup-checks.json`.

Ruff F checks/formatting, Cargo formatting, the accepted isolated locked/offline
release build and `git diff --check` pass. The Rust implementation was not
changed by these follow-ups, so no new GPU mechanism or dependency build was
introduced. No claim is made that the unrelated historical 18-gate production
suite was rerun. The review fixes do not warrant another substantive review.

**Decision:** close 5nb as the completed, numerically qualified negative trial.
Keep it diagnostic only. No fallback, configuration sweep, production promotion,
frozen long-row change, cwk.5 restart or Stage 6 work.
